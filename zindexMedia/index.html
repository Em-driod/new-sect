Part 1: Z-Index

Think of z-index like stacking papers on a table. The paper with the higher number sits on top.

RULE: z-index only works when the element has a position (relative, absolute, fixed or sticky). It does NOT work on position: static (the default).

Example 1: Overlapping boxes

Red
z-index: 1
Green
z-index: 3
Blue
z-index: 2

Green is on top because 3 is the biggest number. Blue is next (2). Red is at the bottom (1).

Example 2: z-index WITHOUT position (does not work)

Red
z-index: 100
(no position)
Blue
z-index: 1

Red has z-index 100 but no position, so the browser ignores it. Blue still covers it.

Part 2: Media Queries

A media query lets us say: "IF the screen is this size, THEN use these styles." This is how one website looks good on a phone, a tablet and a laptop.

You are on a PHONE screen (below 600px)

You are on a TABLET screen (600px - 991px)

You are on a LAPTOP screen (992px and above)

TRY IT: Make your browser window smaller and bigger, and watch the box above change. (Or press F12 and click the phone icon.)
